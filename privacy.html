一句话结论：你的日程数据默认只保存在你自己的设备上。我们没有服务器、不设账号、不接广告、不做用户画像。如果你主动开启 iCloud 同步，数据存在你自己的 iCloud 私有空间里 —— 那是你的账号，我们同样看不到。

1. PlanDeck 是什么

PlanDeck 是一个排期与进度管理工具，帮你把手上多个项目的安排收进一张清单：左边月历看全局，右边日程表填细节，进度与合计开销一起呈现。

月历排期›清单进度›合计开销

你可以自定义列（文本框 / 数值 / 时间 / 文件存放 / 多选框），把它改成自己工作流的样子 —— 做视频叫「脚本 / 拍摄 / 剪辑」，写稿叫「提纲 / 初稿 / 定稿」。这些都只是文字与数字，不涉及任何媒体素材本身。

2. 我们收集的信息

我们不收集任何个人信息。PlanDeck 没有账号系统，不需要注册或登录，也不要求你提供姓名、邮箱、手机号等任何身份信息。

  • 我们没有用于存放你数据的服务器，因此技术上也没有地方可以读到你的日程内容。
  • 我们不接入任何第三方统计、分析或广告 SDK，不埋点、不追踪、不做用户画像。
  • 我们不读取你的通讯录、相册、定位、相机或麦克风。App 内也没有广告。
  • 如你已在系统设置中开启「与开发者共享」，Apple 可能向我们提供匿名崩溃日志。这类日志不包含你的日程内容，也无法识别你的身份，可随时在系统设置中关闭。

3. 数据如何存储

你录入的日程名称、日期、数值、文件路径、勾选进度等，默认保存在设备本地，属于操作系统为 App 分配的沙盒空间。

  • 默认状态：只存本机。不联网、不上传、不经过我们。
  • 可选：iCloud 同步。这是一项需要你手动开启的功能（属于 Pro 权益）。开启后，数据存放于你自己的 iCloud 私有数据库，用于在 Mac、iPhone、iPad 之间保持一致。该空间归你的 Apple ID 所有，我们无法访问。
  • 导出备份会把数据写成一个 JSON 文件，保存位置由你在系统文件选择器中自行决定；若你选择存进 iCloud 云盘，那么同步行为由系统管理，与 App 无关。
  • 删除 App 会连同本机数据一并清除。换设备或重装前，请先用导出功能备份。

4. 我们申请的权限

PlanDeck 只申请下面这几项权限，每一项都只在对应功能被使用时才生效：

权限用途是否必需
日历（写入与读取）把带日期的日程同步到系统日历，并把你在日历里改动的日期同步回来可选，首次使用时询问
iCloud（CloudKit）在你自己的设备之间同步数据可选，需手动开启
用户所选文件导入 / 导出备份，选择文件或文件夹路径仅在你主动操作时
网络仅在开启 iCloud 同步时用于与此前所述的私有数据库通信其余情况不发起请求

日历同步使用一个独立的「PlanList」日历，不会与你的私人日程混在一起，可随时整体关闭或撤销授权。若你从未开启日历同步，App 不会读取你的日历。

除此之外，我们不申请也不使用定位、相机、麦克风、通讯录、健康数据、蓝牙或广告标识符等任何权限。

5. 关于 Pro 内购

PlanDeck 的基本功能完全免费，包括月历、清单、卡片视图、模板制作、导出备份和全部外观主题。

「永久解锁」是一次性买断，不是订阅，用于解锁导入备份、日历同步与 iCloud 同步。任意一端解锁，同一 Apple ID 下的 Mac / iPhone / iPad 通用。

付款流程完全由 Apple 的 App Store 完成，我们不会接触也不会记录你的支付方式、卡号或账单信息。

6. 你的控制权

  • 你可以随时在 App 内清空全部数据，无需向我们提出申请。
  • iCloud 同步开关由你掌握：关掉后数据不再离开本机。
  • 日历同步可随时整体关闭，已写入的事件可由你在系统日历中删除。
  • 卸载 App 即可移除其在本机保存的所有内容。

7. 儿童隐私

PlanDeck 是面向有一定排期需求的成年用户的生产力工具，并非面向 13 岁以下儿童设计的产品。由于 App 本身不收集任何个人信息，这一点在技术上即已成立。
